HR Analytics Dashboard – Employee Attrition Insights

I designed this interactive Power BI dashboard to analyze and visualize employee turnover trends using data cleaned and prepared with Python (Pandas, NumPy, Matplotlib).

---------------------------------------------------------------------------------------------------------------------------------------------------------------------


Key Highlights:

Total Employees: 1480 | Average Salary: 5K | Average Age: 33

Overall Attrition Rate: 16.1% across departments

Attrition Breakdown by Age, Education, Salary, Job Role, and Tenure

Interactive filters for Gender, Marital Status, and Job Role

Insights: Higher attrition among younger employees (26–35) and lower salary brackets (<5K)

---------------------------------------------------------------------------------------------------------------------------------------------------------------------


Tech Stack:

Python – Data Cleaning & Transformation

Power BI – Data Modeling & Visualization

This project helped uncover key patterns behind employee turnover, supporting HR teams in building better retention and engagement strategies.
